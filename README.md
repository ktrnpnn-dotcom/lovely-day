# Lovely day

Космический медиаплеер, который живёт у вас на компьютере: три настоящих трека, живое радио SomaFM, круговая «плёночная» перемотка и 16 тем (время суток × сезон).

Это обычный Vite + React проект. Без аккаунтов, без облака, без базы.

## Запуск у себя

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:43147.

Если mp3 ещё нет в public/audio/:

```bash
bash scripts/fetch-media.sh
```

## Как слушать

- Плейлист слева на большом экране, на телефоне — кнопка «Треки»
- Кнопка play, соседние треки, громкость
- Крутите кольцо вокруг обложки, чтобы перематывать
- Удерживайте кольцо: 2 секунды нажатия = 15 секунд песни, со звуком кассеты
- Радио — Deep Space One, Drone Zone, Space Station Soma
- Иконки утро/день/вечер/ночь и весна/лето/осень/зима меняют палитру

## Музыка

- HoliznaCC0 — фрагмент «20 Minute Meditation 1» и «Ease into Night», CC0
- Hypnotronic Man — «Space Traveler», CC0
- Радио — потоки SomaFM для личного прослушивания

## Стек

Vite, React 19, TypeScript, Tailwind CSS 4, lucide-react.
